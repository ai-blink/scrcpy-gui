# scrcpy 설정 GUI v0.5.0

PC에서 명령어를 입력하지 않고 Blink Link 휴대폰 앱을 설치·준비하고, 조건별 매크로를 구성할 수 있습니다. 동봉 Android 앱 버전은0.3.2입니다.

## 주요 변경

- **Blink Link 설정**에서 휴대폰 선택→APK 설치→최초 권한 부여→권한 확인→앱 열기까지 처리합니다. PC 실행 파일에 APK와 .NET 런타임이 포함됩니다.
- 휴대폰의 등록 Wi-Fi 무선 연결 복구, 연결·설정·기록 화면과 매크로 편집기를 추가했습니다.
- 매크로는 시간·충전·Wi-Fi·화면·수동 조건과 알림·음성·대기·앱 열기 알림·음량·진동·디버깅 복구를 순서대로 조합합니다. 복제·순서 변경·JSON 백업·실행 기록을 제공합니다.
- 음성 재실행 멈춤, 예약 동시 실행 누락, 감시 버튼 상태 불일치, 자체 백업 복원과 편집 초안 유실을 수정했습니다.
- APK의 수동 ADB 명령 안내를 PC 버튼 안내로 바꾸고, 오프라인 PC/휴대폰 HTML 설명서를 제공합니다.

## 받는 파일

처음 사용한다면 **ScrcpyGui-v0.5.0-win-x64.zip**을 받아 새 폴더에 풀고 `ScrcpyGui.exe`를 실행하세요.

- `ScrcpyGui.exe`: .NET 런타임과 Blink Link0.3.2 APK가 포함된 Windows x64 실행 파일.
- `ScrcpyGui-v0.5.0-win-x64.zip`: 실행 파일·APK·두 HTML 설명서·빠른 시작 안내·라이선스.
- `BlinkLink-0.3.2-debug.apk`: 휴대폰에 직접 설치할 때 사용하는 별도 파일. 일반 사용자는 PC 버튼으로 준비하면 됩니다.
- `scrcpy-install-guide.html`, `BlinkLink-guide.html`: PC 및 휴대폰 앱 설명서.
- `SHA256SUMS.txt`: 위 파일의 SHA-256 목록.

scrcpy와 adb 자체는 포함하지 않습니다. [공식 scrcpy Windows 배포본](https://github.com/Genymobile/scrcpy/releases/latest)을 준비한 뒤 PC 앱의 설정에서 경로를 지정하세요. 기존 사용자는 개인 설정 JSON을 보존하세요.

## 확인한 범위

- Blink Link PC 준비 로직23개 검사와 고정 Hyper-V 게스트의 WPF UI8개 검사 통과.
- Android16 AVD에서 실제 설치·권한 부여·적용 확인·앱 열기와 APK0.3.2의 새 안내를 확인.
- 복구 정책10개·재시도 예산14개·음성 세션8개 검사 통과. Windows UI 검사는 가짜 ADB, 실제 ADB 동작은 Android AVD에서 별도로 확인했습니다.
- 삼성 실물 기기의 절전·네트워크 신뢰 유지·실제 음성 출력은 별도 검증 범위입니다. APK는 개발 서명 개인 시험 버전입니다.
- 변수·분기·반복·화면 자동 클릭 등 MacroDroid 전체 기능은 포함하지 않습니다.
