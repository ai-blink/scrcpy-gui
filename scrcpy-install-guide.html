01 / INSTALL ROUTE

원하는 방법을 고르세요.
기준은 언제나 공식 소스입니다.

처음이라면 GUI 안의 공식 최신 버전 설치가 가장 간단합니다. 이미 명령줄 설치를 선호한다면 공식 Windows 문서가 안내하는 패키지 관리자도 사용할 수 있습니다.

03 / TRUST, THEN RUN

다운로드는 끝이 아니라,
검증이 끝나야 합니다.

GUI 설치는 승인 전에 공식 릴리스가 제공한 SHA-256을 보여주고 다운로드 파일과 대조합니다. 수동으로 ZIP을 받았다면 Windows에서도 같은 값을 직접 확인할 수 있습니다.

PowerShell · SHA-256 CHECK
PS> Get-FileHash .\scrcpy-win64-v4.1.zip -Algorithm SHA256

Algorithm       Hash                                      Path
---------       ----                                      ----
SHA256          <GitHub Releases에 표시된 공식 SHA-256>  .\scrcpy-win64-v4.1.zip

PS> .\scrcpy.exe --version
scrcpy 4.1
✓

허용하는 출처는 하나입니다.

설정 GUI의 자동 설치는 Genymobile/scrcpy 공식 GitHub 릴리스의 정확한 Windows 64-bit ZIP URL만 허용합니다.

  • URL 직접 입력 없음
  • 제3자 미러 없음
  • 자동 백그라운드 업데이트 없음
  • 해시가 없거나 다르면 설치 중단

04 / WIRELESS PAIRING

케이블 없이 시작하는
무선 디버깅 페어링.

Android 11 이상에서는 무선 디버깅 페어링을 한 번 완료하면 이후 adb devices가 mDNS로 기기를 자동 발견합니다.

폰에서 할 일

폰 설정을 바꾸는 단계입니다. 개발자 옵션과 무선 디버깅을 직접 켜는 데 동의한 경우에만 진행하세요.

  1. 설정 → 개발자 옵션에서 무선 디버깅을 켭니다.
  2. 무선 디버깅 항목을 열고 페어링 코드로 기기 페어링을 누릅니다.
  3. 표시되는 IP:포트와 6자리 코드를 PC에 준비합니다.

PC에서 할 일

공식 scrcpy 배포판에는 일반적으로 adb가 함께 포함됩니다. 페어링을 마친 뒤에는 별도 adb connect가 필요 없습니다.

PS> adb pair 192.168.0.5:41234 123456

PS> adb devices
List of devices attached
<자동 발견된 기기>  device
주의: adb tcpip 5555 고정 포트 방식은 안내하지 않습니다. 무선 디버깅 포트는 재접속마다 바뀔 수 있고, USB가 필요해질 수 있습니다.
CONTROL SAFETY입력이 갇혔을 때
마우스 방식을 uhid 또는 aoa로 선택하면 포인터가 scrcpy 창에 캡처될 수 있습니다. 이 옵션을 켜기 전에 탈출법을 기억하세요: Alt 또는 Windows 키를 누르면 캡처를 풀고, 다시 누르면 재캡처합니다. 전체화면은 Ctrl + F, 창 종료는 Ctrl + Q입니다.
