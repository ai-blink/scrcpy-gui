실행과 연결

  1. 통합 ZIP을 새 폴더에 풉니다. ScrcpyGui.exe를 실행하세요. PC에 .NET이나 PowerShell7을 따로 설치할 필요가 없습니다.
  2. scrcpy 공식 Windows 배포본을 준비합니다. 공식 다운로드 페이지에서 받으세요. scrcpy와 adb 자체는 이 ZIP에 포함하지 않습니다.
  3. 왼쪽 ‘설정’에서 실행 파일을 확인합니다. 자동으로 찾지 못하면 scrcpy.exe와 adb.exe를 찾아 지정합니다. Android16에는 scrcpy4.0 이상을 사용하세요.
  4. 휴대폰을 연결합니다. 이미 허용한 USB 디버깅 연결이 있으면 상단 새로고침으로 확인합니다. 무선은 개발자 옵션→무선 디버깅→페어링 코드로 기기 페어링을 열고, PC 상단 페어링에 표시된 주소·코드를 입력합니다. Android 시스템의 첫 승인은 사용자가 직접 해야 합니다.
  5. 대상 기기를 고르고 ‘새 창 실행’을 누릅니다. 기기가 보이지 않으면 같은 Wi-Fi인지 확인하고 기기 찾기를 누르세요.

기존 사용자는 앱을 닫은 뒤 실행 파일을 교체할 수 있습니다. 개인 설정 JSON 파일은 삭제하지 마세요. 통합 ZIP에는 개인 설정과 로그를 넣지 않았습니다.

Blink Link 설치와 최초 권한

상단 Blink Link 설정→휴대폰 선택→설치 · 권한 설정

상단 Blink Link 설정을 열고 대상 휴대폰을 확인한 뒤 이 휴대폰에 설치 · 권한 설정을 누르세요. APK는 PC 실행 파일에 들어 있습니다. ADB 명령어나 기기 주소를 직접 입력할 필요가 없습니다.

PC가 기존 데이터를 유지하며 설치하고, 최초 권한의 실제 적용을 확인한 뒤 휴대폰에서 앱을 엽니다. 휴대폰 앱의 설정에서 위치·알림 권한을 허용하고 사용할 Wi-Fi를 등록하세요.

기본 연결 복구와 직접 만든 매크로의 조건 감시는 각각 시작하고 멈춥니다. ‘무선 디버깅 켜짐’은 PC 미러링 연결 성공 판정이 아니므로 PC에서 연결을 확인하세요.

진행 중에는 대상 기기를 바꿀 수 없습니다. 실패하면 표시된 이유를 확인하고 연결 후 재시도하세요. 취소는 이미 설치한 앱이나 적용한 권한을 되돌리지 않습니다.

화면과 휴대폰 조작판

위치기능
상단휴대폰 선택·관리, 새로고침, 기기 찾기, 페어링, Blink Link 설정.
왼쪽 범주화면·창·전원·입력·소리·녹화 등 scrcpy 옵션과 실행 파일 위치 설정.
휴대폰 조작판미러링 창 밖에서 뒤로·홈·최근 앱·스크롤 등을 누르는 보조 패널. 배치와 크기·드웰 등은 조작판 설정에서 고릅니다.
하단프리셋 선택·저장·삭제 및 새 창 실행. 일반 옵션 변경은 다음 실행에 적용됩니다.
고급 · 자세히 보기실행될 명령어 확인과 직접 인자 편집. 평소에는 펼치지 않아도 됩니다.

기기 선택은 프리셋과 별도로 유지합니다. 현재 옵션은 자동 저장됩니다. GUI를 닫아도 이미 실행한 미러링 프로세스를 강제 종료하지 않습니다. 안구마우스에서 화면 탈출이 어려운 포인터 캡처 모드는 실행 전에 차단하고 sdk 모드를 안내합니다.

휴대폰 매크로 사용

Blink Link의 내 매크로 열기→새 매크로 만들기에서 실행 조건과 동작 순서를 고릅니다. 시간·충전·Wi-Fi·화면·수동 조건과 알림·음성·대기·앱 열기 알림·음량·진동·연결 복구를 조합할 수 있습니다.

자동 실행은 매크로별 자동 실행 허용과 전체 조건 감시 시작이 모두 필요합니다. 매크로 감시는 재부팅·강제 중지·프로세스 종료 후 직접 다시 시작합니다. Android 설명서의 예제·백업·문제 해결을 확인하세요.

문제 해결

휴대폰이 목록에 없어요

Android 디버깅 허용과 PC의 adb 경로를 확인하세요. 무선은 같은 네트워크에서 페어링 후 기기 찾기를 사용합니다. 허용 대기 상태에서는 휴대폰에서 시스템 창을 확인해야 합니다.

Blink Link 설정 버튼이 없어요

기존 PC 앱을 닫고 v0.5.0의 ScrcpyGui.exe를 실행하세요. 초기 설정 APK를 따로 찾아 넣을 필요는 없습니다.

설치 또는 권한 설정이 실패해요

선택한 기기 연결을 확인하고 재시도하세요. 휴대폰 사용자가 도중에 바뀌면 권한 부여 전에 중단합니다. 다른 서명 앱이나 더 높은 버전을 강제로 지우거나 낮추지 않습니다. 개발 서명이 다른 기존 앱은 원래 배포본과의 호환성을 확인해야 합니다.

무선 디버깅이 켜져도 미러링이 안 돼요

PC에서 기기를 다시 찾고 새 창 실행을 누르세요. Android 잠금 해제·네트워크 허용 창·주소 변경은 별도 확인이 필요할 수 있습니다.

포함 범위와 검사

통합 ZIP에는 PC 실행 파일, Android APK, PC/휴대폰 HTML 설명서, 빠른 시작 안내와 라이선스가 들어 있습니다. scrcpy·adb·SDK·개인 설정·VM 디스크·로그·서명 키는 포함하지 않습니다.

PC 준비 로직23개와 격리 Hyper-V의 Windows UI8개 검사를 통과했습니다. Windows UI는 가짜 ADB를 사용했으며, 실제 설치·권한 부여·확인·앱 열기는 Android16 AVD에서 따로 검증했습니다. 삼성 실물 기기의 절전·네트워크 신뢰 유지·실제 음성 출력은 아직 검증하지 않았습니다.

Android APK는 개발 서명 개인 시험 버전입니다. 변수·분기·반복·화면 자동 클릭 등 MacroDroid 전체 기능은 지원하지 않습니다. 릴리스 페이지에서 파일과 SHA-256 목록을 확인할 수 있습니다.

scrcpy 설정 GUI v0.5.0 · 이 설명서는 인터넷 없이 열 수 있습니다. 공식 다운로드와 릴리스 링크에는 인터넷 연결이 필요합니다.
