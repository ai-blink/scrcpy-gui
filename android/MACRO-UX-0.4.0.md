# Macro UX 0.4.0

2026-11-11 · Android 로컬0.4.0 / PC 로컬0.5.1. 공개 v0.5.0 릴리스(Android0.3.2)는 그대로 유지한다.

## 변경 범위

무선 복구 하나가 아니라 현재 지원하는7개 실행 조건과7개 동작의 입력 UX 전체를 개선했다. 공통 ‘내용 / 값’ 칸과 패키지명·밀리초·시각 형식 직접 입력을 없앴다.

| 기능 | 사용자가 조작하는 방법 |
|---|---|
| 매일 시각 | Android 시간 선택 창. 시각 입력 형식은 내부에서 생성 |
| 충전 시작·종료, 화면 켜짐·잠금 해제·수동·Wi-Fi | 실행 조건 목록에서 선택 |
| Wi-Fi 추가 조건 | 현재 연결/등록/기존 저장 네트워크 목록 또는 제한 없음 |
| 알림·텍스트 읽기 | 평소 문장 입력 또는 예문 버튼 |
| 대기 | 초 단위 슬라이더와1/3/5/10/30초 버튼 |
| 앱 열기 | 설치된 실행 가능한 앱을 이름으로 검색·선택 |
| 음량 | 음소거·작게·보통·크게·최대 버튼 및 퍼센트 슬라이더 |
| 진동 | 짧게0.2초·보통0.5초·길게1초. 밀리초 변환은 내부 처리 |
| 디버깅 복구 | 값 입력 없이 동작 선택 |

매크로 이름은 선택 사항이며 비우면 자동 이름을 생성한다. 저장 버튼을 편집 화면 하단에 고정했다. ‘예제에서 시작하기’에서 충전 알림·아침 음성·설정 앱 열기 초안을 열어 조정할 수 있다. 예제는 저장 전 실행하지 않는다.

기존 JSON의 정수 동작 ID와 값 형식은 유지한다. 예전 매크로의 패키지 이름/SSID와 임의 진동 길이는 로드 후 바꾸지 않으면 그대로 보존한다. 앱이 삭제됐으면 알아보기 쉬운 문구로 표시한다. Wi-Fi 목록은 스캔/저장 목록 권한을 새로 요구하지 않고 현재 확인 가능한 이름·기본 복구 등록 이름·기존 매크로의 저장 이름만 사용한다.

앱 선택 목록은 백그라운드에서 불러온다. 이 로딩 오류는 메시지로 처리하고 화면 종료 후 결과를 적용하지 않는다. 선택 결과는 내부 패키지 ID로 저장하되 사용자에게 입력을 요구하지 않는다. 음성/알림 및 슬라이더 초안은 재생성 후 복원하며 시간 선택 창도 네이티브 상태 Bundle로 복원한다.

## 검사

실행: `python android/tests/emulator_macro_ux.py` (`emulator_macros.py`는 선택기/저장 관리 회귀까지 순서대로 실행하는 진입점). 전용 AVD BlinkLink16 / emulator-5580만 허용하며 호스트나 실제 휴대폰에 입력하지 않는다.

- 7가지 트리거 선택과 네이티브 시각 선택, 현재 Wi-Fi 선택.
- 알림 예문, 음성 초안의 테마 변경 복원, 대기·음량·진동 빠른 선택, 앱 이름 선택, 입력 없는 복구.
- 7개 동작의 순서와 실제 저장 값, 자동 이름, 고정 저장 버튼, 예제 저장.

앱을 debuggable로 바꾸지 않았다. 저장 결과는 제품에 포함하지 않는 같은 서명 시험 APK의 MacroUxReadout으로 읽고, 프로세스가 끝난 뒤 다시 앱을 연다. GUI만 보는 검사와 실제 저장 결과를 구분한다. 증거: `work/android-lab/macro-ux040/` PNG/XML/results.json.

정책·예산·음성 세션32개 검사와 PC 준비 로직23개 검사 통과. 실제 삼성 기기·앱 목록 대규모 성능·TalkBack/안구마우스 수락은 별도다. 변수·분기·반복이나 MacroDroid의 미구현 동작을 이번 UX 작업으로 추가한 것은 아니다.

산출물: `app/android/BlinkLink-0.4.0-debug.apk`, `app/ScrcpyGui-v0.5.1.exe`. Android HTML 설명서도 새 선택 UI에 맞춰 갱신했다.
