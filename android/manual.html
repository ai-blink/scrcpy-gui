먼저 알아두기

Blink Link에는 두 가지 감시 기능이 있습니다. 무선 연결 복구와 직접 만든 매크로의 조건 감시는 각각 시작하고 멈춥니다.

기능하는 일시작 위치
무선 연결 복구등록한 Wi-Fi에서 꺼진 무선 디버깅을 다시 켭니다.연결 → 자동 복구 시작
매크로 조건 감시시간·충전·Wi-Fi·화면 상태에 따라 사용자가 만든 동작을 실행합니다.내 매크로 열기 → 조건 감시 시작

‘무선 디버깅 켜짐’은 PC 화면 연결 성공과 다릅니다.
휴대폰에서 준비가 끝나면 PC의 scrcpy-gui에서 기기를 찾아 연결하세요.

이 설명서는 S23 Ultra / One UI 8.5 / Android 16 사용을 목표로 작성했습니다. 현재 검증은 Android 16 가상 기기에서 수행했으며, 삼성 실물 기기의 설치·절전·네트워크 신뢰 유지와 실제 PC 연결은 별도 확인이 필요합니다.

설치와 최초 설정

  1. 휴대폰과 PC를 한 번 페어링합니다.

    휴대폰 개발자 옵션 → 무선 디버깅 → 페어링 코드로 기기 페어링을 열고, PC의 scrcpy-gui에서 페어링하세요. 두 기기는 통신할 수 있는 Wi-Fi에 연결돼 있어야 합니다.

  2. APK를 설치합니다.

    위의 APK 링크에서 파일을 받으세요. 휴대폰에서 직접 열거나 PC의 ADB로 설치할 수 있습니다. 기존 Blink Link 사용자는 같은 개발 서명 키의 0.3.1을 덮어 설치할 수 있습니다.

  3. PC에서 최초 권한을 한 번 부여합니다.

    연결된 기기의 ADB 주소를 확인하고 아래 명령의 <기기주소:포트>를 바꿔 실행합니다. 페어링용 포트와 실제 연결용 포트는 다를 수 있습니다.

    adb -s <기기주소:포트> shell pm grant kr.blinklabs.blinklink android.permission.WRITE_SECURE_SETTINGS

    개발용 프로젝트 폴더에서 설치와 권한 부여를 함께 하려면 다음 PowerShell 명령을 사용합니다.

    .\android\install.ps1 -Serial '<기기주소:포트>' -GrantPermission

    두 명령 모두 주소를 실제 값으로 바꾼 뒤 실행해야 합니다. HTML 설명서에서 자동으로 실행되지는 않습니다.

  4. 앱에서 Wi-Fi 확인 권한을 준비합니다.

    Blink Link → 설정 → 권한 설정 방법을 펼치세요. 정확한 위치·알림 권한을 허용하고, 앱의 위치 권한을 항상 허용으로 설정합니다. Android의 위치 설정도 켭니다. Wi-Fi 이름을 확인하기 위한 조건이며 앱은 위치 좌표를 저장하거나 전송하지 않습니다.

  5. 사용할 Wi-Fi를 등록합니다.

    설정에서 현재 Wi-Fi 등록을 누르고 이름을 확인하세요. 본인이 관리하는 네트워크를 등록합니다. 현재 한 개의 Wi-Fi 이름을 저장하며 새로 등록하면 기존 이름을 바꿉니다.

  6. 자동 복구를 시작하고 PC에서 연결합니다.

    연결 화면에서 자동 복구 시작 → 시작을 누릅니다. Android의 허용 창이 나오면 네트워크를 확인하세요. 사용할 수 있는 경우 이 네트워크에서 항상 허용을 선택합니다. 이후 PC scrcpy-gui에서 실제 화면 연결을 확인합니다.

감시가 자주 중단되면 앱의 설정 → 앱 권한 · 배터리 설정에서 삼성 배터리 설정의 ‘제한 없음’을 확인할 수 있습니다. 제조사의 절전 동작까지 완전히 방지하는 것은 아닙니다.

연결 복구 사용

버튼 / 화면사용할 때
지금 한 번 복구등록 Wi-Fi에서 디버깅 켜기를 직접 요청합니다. 자동 감시를 시작하는 버튼은 아닙니다. 화면에서 Wi-Fi를 확인할 수 있고 PC 권한이 있으면 백그라운드 위치 권한 없이도 사용할 수 있습니다.
자동 복구 시작등록 Wi-Fi에서 무선 디버깅 꺼짐을 감시합니다.
자동 복구 일시정지감시만 멈춥니다. 현재 무선 디버깅 상태는 유지합니다.
감시 다시 시작Android에서 중지된 감시를 사용자가 다시 시작합니다.
설정위치 권한·Wi-Fi 등록·PC 권한의 준비 상태와 설명을 확인합니다.
기록기본 연결 복구의 최근 기록을 읽고 복사합니다.
디버깅 끄고 복구 정지설정 화면 아래에 있습니다. 확인 후 기본 자동 복구와 무선 디버깅을 끄도록 요청합니다. 연결 중인 PC 화면이 끊길 수 있습니다.

기본 연결 복구는 약 30초 점검과 설정·네트워크 콜백을 사용합니다. 재부팅 후 첫 잠금 해제와 앱 업데이트 이후에도 사용자가 시작한 감시를 재개할 수 있습니다. 강제 중지한 경우에는 앱을 열고 직접 다시 시작하세요.

자동 켜기 요청은 최근 5분에 최대 3회, 요청 사이 최소 5초로 제한됩니다. 요청 실패도 횟수에 포함됩니다. 대기 중에는 연결 화면의 ‘지금 한 번 복구’를 사용할 수 있습니다. 매크로의 디버깅 복구 동작은 기존 요청 예산을 사용합니다.

매크로 만들기

언제 실행할까요?→추가 조건 확인→동작을 순서대로 실행
  1. 연결 화면에서 내 매크로 열기 → 새 매크로 만들기를 누릅니다.
  2. 알아보기 쉬운 이름을 입력하고 실행 조건을 선택합니다.
  3. 필요하면 ‘충전 중에만’ 또는 Wi-Fi 이름을 추가합니다. 두 조건을 지정하면 둘 다 맞아야 합니다.
  4. 동작 추가에서 종류와 값을 입력하고 추가 / 적용을 누릅니다.
  5. 여러 동작은 위에서 아래 순서로 실행됩니다. ‘위로 / 아래로 / 삭제’로 정리합니다.
  6. 매크로 저장을 누릅니다. 저장 버튼이 보이지 않으면 본문을 아래로 스크롤하세요.

자동으로 실행하려면 두 가지를 켜세요

개별 매크로의 자동 실행 허용을 켠 뒤, 목록 위에서 조건 감시 시작을 누릅니다. 매크로 목록의 실행 버튼은 개별 자동 허용이 꺼져 있어도 수동 실행하지만, 추가 조건은 그대로 확인합니다.

멈추기와 기록 보기

매크로 목록의 조건 감시 중지 또는 감시 알림의 전체 중지로 감시와 진행 중인 매크로를 멈출 수 있습니다. 기본 무선 연결 복구는 별도로 일시정지합니다. 매크로 실행 기록에서 시작·완료·실패·추가 조건 불일치 등의 결과를 확인하세요.

동작 설정 창에서 작성하던 종류와 값은 화면 회전이나 테마 전환 후 복원됩니다. 목록으로 나갈 때는 매크로 저장을 눌러야 변경이 저장됩니다.

실행 조건: 매일 지정 시각 → 09:00
첫 동작: 미디어 음량 → 40
두 번째 동작: 텍스트 읽기 → 오늘 일정을 확인할 시간입니다.

음량을 바꾸고 싶지 않으면 첫 동작을 빼세요. TTS 언어와 소리가 준비돼 있는지 목록의 실행 버튼으로 먼저 확인합니다. 종료 후 음량은 자동 복원되지 않습니다.

한 번 눌러 연결 준비하기

실행 조건: 수동 실행
추가 조건: 사용할 Wi-Fi 이름
첫 동작: 무선 디버깅 복구 → 값 없음
두 번째 동작: 알림 표시 → PC의 scrcpy에서 연결을 확인하세요.

Wi-Fi 이름은 정확하게 입력합니다. 기본 연결 설정에서 같은 Wi-Fi를 등록하고 PC 권한을 준비해야 합니다. 마지막 알림은 연결 성공 판정이 아니라 사용자가 확인할 안내입니다.

백업과 복원

  1. 매크로 목록 아래의 매크로 내보내기를 누르고 Android 파일 선택기에서 저장 위치를 고릅니다.
  2. 복원할 때 매크로 가져오기에서 Blink Link JSON 파일을 선택합니다.
  3. 확인 후 현재 목록에 추가됩니다. 기존 항목을 덮어쓰지 않습니다.
  4. 가져온 매크로는 모두 자동 실행이 꺼진 상태입니다. 내용과 조건을 확인하고 필요한 항목만 켭니다.

파일은 UTF-8 기준 최대 16MiB, 매크로는 기존 목록과 합쳐 최대 100개입니다. 지원하지 않는 버전이나 잘못된 값이 있으면 파일의 항목 전체를 추가하지 않습니다. 복제한 매크로도 꺼진 상태로 생성됩니다.

이 파일은 Blink Link 매크로 정의용입니다. MacroDroid 내보내기 파일과 호환되지 않습니다. 기본 연결 복구의 Wi-Fi 등록·Android 권한·PC 페어링·실행 기록을 함께 복원하는 전체 앱 백업도 아닙니다.

문제 해결

Wi-Fi 이름을 확인할 수 없어요

휴대폰 Wi-Fi 연결, 정확한 위치 권한, ‘항상 허용’, Android 위치 켜짐을 확인하세요. 앱의 설정 화면에서 권한 안내를 펼칠 수 있습니다. Wi-Fi 이름을 확인할 수 없으면 자동 연결 복구나 이름 조건이 맞지 않을 수 있습니다.

자동 복구를 켰는데 PC 화면이 연결되지 않아요

앱은 무선 디버깅을 켜도록 요청합니다. Android 허용 창과 잠금 해제 여부를 확인하고, PC scrcpy-gui에서 기기를 다시 찾으세요. 주소·포트가 바뀌거나 페어링이 유지되지 않는 상황은 PC 쪽에서도 확인해야 합니다.

매크로가 자동으로 실행되지 않아요

개별 ‘자동 실행 허용’과 전체 ‘조건 감시 시작’을 모두 확인하세요. 충전·Wi-Fi 추가 조건은 모두 맞아야 합니다. 감시를 시작할 때 이미 연결된 Wi-Fi·충전 상태는 새 이벤트로 처리하지 않습니다. 실행 기록에서 조건 불일치나 실패를 확인하세요.

수동 실행도 안 되거나 중간에 멈춰요

수동 실행도 추가 조건을 확인합니다. 매크로 실행 기록을 열고 실패한 이유를 확인하세요. 알림 권한·알림 채널, TTS 엔진, 앱 패키지 이름, 진동 장치, 디버깅 권한 등을 점검합니다. 실패 뒤의 동작은 실행하지 않습니다.

‘앱 열기’가 알림만 보여요

정상 동작입니다. Android의 백그라운드 화면 실행 제한에 맞춰 알림을 제공합니다. 알림을 직접 눌러 앱을 여세요. 실행할 앱이 설치돼 있고 올바른 패키지 이름인지도 확인하세요.

소리가 안 들려요

휴대폰 기본 텍스트 음성 변환 엔진과 한국어 음성 데이터, 미디어 음량, 블루투스 등 현재 소리 출력 장치를 확인하세요. 음성 읽기의 실제 스피커 출력은 이번 가상 기기 검사로 검증하지 않았습니다.

재부팅하거나 강제 중지한 뒤 멈춰 있어요
