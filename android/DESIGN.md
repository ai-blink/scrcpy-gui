# Blink Link Android 화면 기준

사용자가 안구마우스로 PC를 사용한다는 기존 맥락에 따라, 읽기와 반복 조작에 필요한 시선 이동을 줄인다. 휴대폰의 무선 디버깅 설정값과 실제 PC 연결 성공은 구분한다.

## 화면과 흐름

- **연결:** 무선 디버깅 상태, 자동 감시 상태, 현재 Wi-Fi를 먼저 보여준다. 한 번 복구와 자동 복구 시작/일시정지 버튼은 같은 순서와 위치를 유지한다. 최초 PC 권한·Wi-Fi 등록이 없으면 주 버튼으로 설정에 진입한다.
- **설정:** 위치 권한, 사용할 Wi-Fi, PC 권한의 세 단계. 준비된 단계는 상태 텍스트로 표시하고 권한·PC 명령 설명은 펼칠 수 있다. 연결 종료는 추가 설정에 두고 확인 대화상자를 유지한다.
- **기록:** 로컬 동작 기록과 복사. 선택 중인 텍스트를 주기 갱신으로 덮어쓰지 않는다.
- 하단 세 목적지는 스크롤 밖에 고정한다. 시스템 뒤로 가기는 설정/기록에서 연결로 돌아가며, 연결에서는 Android 기본 종료를 따른다. 회전 후 선택한 화면과 스크롤 위치를 유지한다.

## 시각 규칙

기존 밝은 회색 바탕과 짙은 청색을 유지한다. Android 시스템 글꼴을 사용하고 텍스트 크기는 sp 단위로 14/16/18/20/22/24/28 역할에 맞춰 사용한다. 본문은 16sp, 주요 버튼은 18sp다. 화면 상태에만 강조색을 사용하며, 색 없이도 상태 문구로 판단할 수 있어야 한다.

| 역할 | 밝은 테마 | 어두운 테마 |
|---|---|---|
| 배경 | #F5F7FA | #111820 |
| 기본 글자 | #16283A | #E4ECF4 |
| 보조 글자 | #526272 | #AFBECC |
| 주요 동작 | #173D5B | #B7D3F0 |
| 주요 동작 위 글자 | #FFFFFF | #133149 |
| 선택·피드백 배경 | #E2EBF3 | #21384B |
| 경계선 | #798796 | #718294 |
| 정상 상태 | #145C46 | #9FD8BB |
| 주의 상태 | #855215 | #EBC38B |
| 종료 동작 | #9B3138 | #FFB4B8 |

주요 버튼 최소 높이 64dp, 하단 목적지 최소 높이 56dp, 인접 버튼 간격 최소 8dp. 본문 폭은 최대 600dp로 제한하고 좁거나 낮은 화면에서는 본문만 스크롤한다. 모서리는 12dp, 장식 그림자·자동 이동·진입 애니메이션은 사용하지 않는다. 포커스/호버 경계와 네이티브 ripple을 제공한다.

상태 안내는 하단 탐색 위에 표시하며 접근성 권장 시간 API를 따른다. 위치 설정이나 권한 미비는 설정 화면으로 복구 경로를 제공한다. 모든 외부 설정 이동과 시스템 승인 자체는 Android가 처리한다.

## 확인 범위

Android 가상 기기에서 밝은/어두운 테마, 130% 글자 크기, 세로/가로, 권한 없음, 감시 중단, 뒤로 가기와 주요 조작을 확인한다. 스크린샷은 실제 Android 렌더링으로 생성한다. S23 Ultra 실기와 실제 안구마우스 사용성 수락 검사는 별도다.
