# Blink Link 매크로 · 0.3.0

## 사용

연결 화면의 **내 매크로 열기 → 새 매크로 만들기**에서 이름과 실행 조건을 고르고 동작을 원하는 순서로 추가한다. 동작 수정·위로/아래로 이동·삭제 후 매크로 저장을 누른다.

- **실행** 버튼은 자동 실행 허용 스위치와 관계없이 수동 실행한다. 추가 조건은 수동 실행에도 적용한다.
- 자동 실행은 개별 매크로의 **자동 실행 허용**과 목록 위의 **조건 감시 시작**이 모두 필요하다.
- 감시 중 알림에서 **전체 중지**하면 감시와 진행 중인 매크로를 멈춘다. 강제 중지·재부팅·프로세스 종료 후에는 직접 다시 시작한다.
- 기본 무선 연결 복구는 연결 화면에서 별도로 제어한다. 매크로 감시 중지와 기본 연결 복구 일시정지는 서로 다른 기능이다.
- **복제**하거나 파일에서 **가져온** 매크로는 자동 실행이 꺼진 상태다. 내용을 검토하고 켠다.

## 실행 조건과 동작

| 구분 | 지원 |
|---|---|
| 실행 조건 | 수동, 매일 지정 시각, 충전 시작, 충전 종료, Wi-Fi 연결, 화면 켜짐, 잠금 해제 |
| 추가 조건 | 충전 중에만, 정확히 일치하는 Wi-Fi 이름. 두 조건을 지정하면 둘 다 충족해야 함 |
| 동작 | 알림, 텍스트 음성 읽기, 대기, 앱 열기 알림, 미디어 음량, 진동, 무선 디버깅 복구 요청 |
| 편집·관리 | 이름, 개별 자동 실행 허용, 동작 순서 변경, 복제, 삭제 확인, 실행 기록, JSON 가져오기·내보내기 |

앱 열기는 **패키지 이름**(예: `com.android.settings`)을 입력한다. 앱이 보이지 않는 상태에서 임의로 화면을 열지 않고, 앱 실행 알림을 전달한다. 사용자가 알림을 누르면 열린다. 알림을 전달한 다음 동작으로 진행하며, 앱이 열린 결과를 기다리지는 않는다.

음성 읽기는 Android에 설치된 기본 TTS 엔진·언어·음량 설정에 따른다. 요청 성공만으로 완료 처리하지 않고 엔진의 완료 콜백을 기다린다. 엔진 오류나 시간 초과는 실패로 기록한다. 실제 스피커에서 들리는지는 별도 확인이 필요하다.

Wi-Fi 이름에는 정확한 위치·항상 허용·위치 켜짐이 필요할 수 있다. 매크로 화면에서 권한을 우회하지 않으며 기존 설정 화면으로 준비한다. 무선 디버깅 동작도 등록 Wi-Fi·PC 권한과 기존 재시도 예산을 요구한다. 켜기 요청 처리 완료는 PC 연결 성공을 뜻하지 않는다.

## 실행 규칙

- 순서대로 실행한다. 실패한 동작에서 남은 순서를 중단한다. 음량 등 이미 실행한 변경을 자동으로 되돌리지는 않는다.
- 매크로마다 중복 실행을 차단한다. 동시 최대 4개, 동작 최대 16개, 대기 1회 0~30초·합계 최대 120초, 다음 단계로 넘어갈 때 실행 시간이 180초를 넘으면 중단한다. 음성 읽기 한 단계의 완료 대기는 최대 60초다. 자동 이벤트는 같은 매크로에 최소 5초 간격을 둔다.
- 대기 중 전체 중지·정의 삭제·자동 실행 해제를 하면 후속 동작이 실행되지 않는다. 수동 실행은 자동 실행 스위치를 무시한다.
- 시각은 매일 `HH:mm`, 현재 분에 한 번만 실행한다. 실행 날짜를 저장하므로 감시를 재시작해도 같은 날 중복 실행하지 않는다. 날짜를 수동으로 과거로 바꾸는 동작은 보장하지 않는다.
- 시각·Wi-Fi·충전은 약 15초마다 확인하고 충전·화면 이벤트도 받는다. 절전 중 지연되며, 놓친 시각의 소급 실행은 하지 않는다. 감시를 시작한 순간 이미 연결된 Wi-Fi·충전 상태를 새 이벤트로 처리하지 않는다.
- 감시 서비스는 사용자 시작 방식이며 Android가 종료한 뒤 자동 재기동하지 않는다. 서비스가 실제 실행 중일 때만 감시 중으로 표시한다.
- 설정 최대 100개, 가져오기 최대 256KB. 지원하지 않는 버전·범위 오류가 있으면 목록 전체를 추가하지 않는다. JSON은 Blink Link 형식이며 MacroDroid 내보내기 파일과 호환되지 않는다.

## 구성

`MacroStore`가 버전 있는 JSON 저장·검증·가져오기와 기록을, `MacroService`가 조건 감시·중복 방지·순차 실행·취소를, `MacroActivity`가 편집 및 Android 문서 선택기를 담당한다. 모두 원본 Java 구현이며 외부 앱 코드나 유료 제한을 변경하지 않는다. 서비스·편집 Activity는 외부 앱에 노출하지 않는다.

이번 버전에는 블루투스·다른 앱 알림 수신·앱 전환 감지·화면 자동 클릭·HTTP·파일 자동 처리·변수·분기·반복을 아직 추가하지 않았다. 동작 종류와 저장 형식을 확장할 수 있는 첫 매크로 엔진이다.

## 검증

전용 Android 16 AVD `BlinkLink16` / `emulator-5580`에서만 검사한다. 실물 기기와 Windows 호스트에 입력하지 않는다.

- `android/build.ps1`: 기존 복구 정책 10건·예산 14건, APK 서명 검사.
- `android/tests/build-instrumentation.ps1`: 제품 APK에 포함되지 않는 별도 테스트 APK 작성. `MacroInstrumentation`은 저장·가져오기·입력 범위·실제 순차 동작·실패·취소·시각 중복·충전·화면 이벤트를 검증하고 정의·기록·음량·배터리 시험 상태를 복원한다.
- `android/tests/emulator_macros.py`: 실제 편집·실행·복제·수정·순서·삭제·프로세스 재시작·다크/큰 글자 UI 검사. 명확히 이름 붙인 시험 매크로를 가상 기기에 남기고 표시 설정을 복원한다.
- 실제 결과·PNG·UI XML: `work/android-lab/macro-030/`. 별도 실기·Samsung 절전, 음성 출력 청취, 잠금 해제 실제 이벤트, Wi-Fi 재연결, 문서 선택기 저장/불러오기 수락 검사는 남아 있다. JSON 내보내기·가져오기 로직과 실제 문서 선택기 검증을 구분한다.

참고한 Android 원문: [백그라운드 Activity 제한](https://developer.android.com/guide/components/activities/background-starts), [TextToSpeech API](https://developer.android.com/reference/android/speech/tts/TextToSpeech).
